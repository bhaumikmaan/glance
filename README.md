# Glance

Unified developer dashboard inside Cursor/VS Code for:

- GitHub and Bitbucket pull request visibility
- Current repository branch/context checks
- Cursor usage insights (MTD usage, recent requests, conversation insights)

## Scripts

- `npm run build` - bundle extension host code
- `npm run watch` - watch/bundle during development
- `npm run typecheck` - run TypeScript checks
- `npm run lint` - run ESLint
- `npm run format` - format code with Prettier
- `npm run format:check` - verify formatting in CI/release
